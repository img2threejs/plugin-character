# Painted skin base from a reference

This authors **painted base tone**, not physical albedo or reflectance. It does not remove lighting, create pores or synthesize micro-detail. Work only on explicitly selected neutral regions; exclude chest, hip and buttock regions, sexualised detail, clothing and features such as brows and mouth. A region name is not proof that its triangles are safe: inspect selections and overlaps before authoring.

1. Admit the reference and record its identity, provenance, usage rights, capture conditions and color management. A hash does not establish rights. Do not infer an unlit palette from an illuminated photograph.
2. Select sufficiently large, clean and representative encoded-sRGB patches per neutral semantic region. Record them and their sources; omit highlights, seams and painted marks as appropriate. `region_tone_targets` rejects endpoint-clipped pixels, empty and undersized patches. This is a conservative clipping test, not a detector of all bad exposures. Choose `min_pixels` from project sampling needs.
3. Compute per-channel medians and **median of each pixel's CIE L*** after linearising sRGB with D65 luminance. L* of a channelwise median or mean is not generally the median of pixel L*. Keep sampling uncertainty and project-approved RGB and L* tolerances separately.
4. Supply existing atlas RGB, non-overlapping neutral region masks, integer island ownership and explicit 3D-adjacent transition bands to `author_region_base`. The transition mask must be contained in its two owned regions. `feather_px` controls bounded blending only within those bands; UV proximity is not 3D adjacency. Review the returned support and per-region counts. Unowned texels remain unchanged.
5. Supply explicit, disjoint corresponding texel pairs to `enforce_mirror_consistency` only where symmetry is intended. Shared UVs cannot encode independent asymmetric marks. Verify the residual; neither correspondence nor symmetry is inferred.
6. `pad_islands` takes an integer map (positive island IDs, zero available texels, -1 protected). It dilates using bounded four-neighbour nearest ownership, leaves equidistant different-island ties untouched, and never wraps at image edges. Keep the padded area in the declared support if changes are authorized there. Supply an independently defined filter footprint; padding is not proof of mip safety.
7. Save a candidate and run `tools/bpy_measure_skin_authoring.py` with `--blend`, `--atlas`, `--regions`, `--targets`, `--options`, `--baseline-blend`, `--subject`, and `--out`. Regions JSON maps each neutral name to `{"object":"Body","vertex_group":"..."}`, `{"object":"Body","material_slot":0}`, or `{"object":"Body","uv_island_triangles":[0,1]}` (the latter is an explicitly verified set of loop-triangle indices, not automatically discovered islands). Vertex-group selection requires all triangle vertices to have positive group weight; no triangle is clipped. Rasterization uses bottom-up Blender pixel ordering and excludes shared/ambiguous texels. Options JSON can contain `pairs` as `[[[row,col],[row,col]], ...]`, `ownership` as an H×W integer array, `padding_radius`, `support` as an H×W boolean array, and `declared` for gate inputs. The baseline blend must contain a same-sized atlas. Each declared reference entry is `{ "value": number, "tolerance": number, "source": "..." }`, under `declared.references` keyed by metric; tone-delta values are normally zero. Padding requires `declared.limits.skin_seam_padding_min_px.value` as the footprint. Run `tools/gate_skin_body.py --evidence EVIDENCE --stage S2B --json`; missing inputs remain unmeasured, never pass. Keep evidence and independently review visual results.

Atlas rasterization considers material slots containing an image-texture node referencing the named atlas, including nodes in nested groups. Node presence does not establish contribution to the rendered material: inspect shader connections and UV mapping. Selected objects without such a material are rejected; unselected triangles in qualifying slots remain overlap candidates.

## Evidence and limits

Density is area-weighted `sqrt(sum UV texel area / sum world area)`. This tool selects declared neutral face and remaining neutral body triangles, so the caller reference must use the same region definition. Tones and tolerances are reference-relative, not a universal palette or calibrated reflectance.

Assess regional distributions and painted transitions instead of hiding defects with a global fill. Resolve geometry independently before texture matching; no historical density, pixel count, head placement or palette is bundled.

**Not established:** pores, scan-derived micro-detail, de-lighting, physically valid albedo, definitive final-asset regional reference distributions, universal color/density tolerances, automatic 3D adjacency, UV island classification, seam correspondence, mip/filter simulation, complete island gutters, or visual fidelity. None receives a fabricated check. `seam_padding_report` checks available nearest-owner layers of equal RGB only; it excludes ties and protected pixels and cannot establish actual filtering performance or continuity across 3D seams.
