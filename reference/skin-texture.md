# Skin texture pipeline

This is a painted **base-colour texture** pipeline, not a substitute for skin weights, geometry, or an assessment of lighting. `J` below means the read-only job `~/.img2/jobs/robin-bikini-transfer-01`; `N` means `~/.img2/jobs/nami-sketchfab-8e496e5a`. `[single-subject]` numbers document a particular asset, not defaults for a different subject. `[behaviour]` describes a mechanism. The NumPy module `tools/skin_texture.py` imports without Blender or Pillow; Pillow is loaded only to write PNG. Images for paint operations are top-down RGB, either uint8 or finite encoded-sRGB floats in [0,1].

1. **Admit the atlas.** Establish source identity, provenance, attribution and permission before use; do not assume an existing image gives redistribution rights. The case used an existing artist-painted source, not a generated or de-lit texture [behaviour; J `history/robin-transfer-9-before-donor-head/native/build_head.py:251-256`]. Read Blender's bottom-up pixel buffer in reverse row order to obtain top-down arrays; reverse it again when writing Blender pixels. No function infers rights or authorizes use.

2. **Classify regions and UV coverage.** `rasterize_regions(positions, triangles, loop_uv, image_shape, predicates, origin='top-down', overlap_policy='exclude')` accepts per-triangle loop UVs `(T,3,2)` in Blender UV coordinates and predicates taking `(3,3)` triangle positions. Predicates select whole triangles (use their centroid if desired), not exact intersections with an anatomical boundary. Rasterization tests texel centres with barycentric tolerance .02 [behaviour; J `history/robin-transfer-9-before-donor-head/native/build_head.py:339-355`]. It returns masks and coverage counts, empty regions, degenerate/off-image triangles, and a shared mask. Every multiple-triangle texel is conservatively shared, including same-region overlaps and some ordinary adjacent edges; default exclusion may therefore remove legitimate boundary pixels. `report` retains them for explicit review and `error` rejects them. Unclassified triangle coverage also competes with classified coverage; shared or mirrored UVs cannot be separately painted safely. `origin='bottom-up'` explicitly reverses output rows. All pixel boxes below are `(x0,y0,x1,y1)`, upper-exclusive on top-down arrays. Caller must protect all competing islands when dilating; no mask can infer absent islands.

3. **Measure tone.** `measure_tone(rgb, mask, statistic='median', color_space='encoded-srgb', luminance_gate=None)` rejects empty/nonfinite samples and returns count, three channels and range diagnostics. Historical encoded luminance is `0.2126R+0.7152G+0.0722B`; a gate is a strict upper bound. Linear mode first decodes sRGB and applies the same coefficients to linear light, so it selects different pixels and cannot be substituted silently. Median and mean are independently selectable. [single-subject] An encoded dark-neck threshold of .80 was used in J `history/robin-transfer-9-before-donor-head/native/build_head.py:385-391`; this was not a reflectance measurement.

4. **Repair and match.** `fill_skin_island` obtains a per-channel encoded-sRGB median from an explicit sample mask and fills the island plus bounded four-neighbour dilation. `protected_mask` blocks both entry and propagation, and must cover adjacent/ambiguous islands. The image outside support is byte-identical; empty sample or island is an error. [single-subject] Three dilation iterations filled 19,383 pixels; the leg median changed from `[.94118,.74902,.63137]` toward `[.98824,.85098,.75686]` [J `evidence/head-report.json:315-330`]. `tone_match_report` reports per-channel before/after medians and counts where Euclidean RGB distance from the respective median exceeds .08; no pixels is an error. It does not evaluate texture quality or lighting.

   `lift_shadow` measures a dark subset and reference, then computes `gain=referenceMedian/max(darkMedian,.001)`. Dilate twice and blur six times by `(centre + four neighbours)/5` using bounded edge replication; multiply by `1-smoothstep(.75,.88,encodedLuminance)` and strength .7. The `params` dictionary can explicitly override `dark_luminance`, `dilation`, `blur_iterations`, `darkness_gate` and `strength`. The returned support includes the blur halo, not only the input mask; bright pixels outside the gate remain untouched. Empty dark or reference samples fail. [single-subject] The measured gain was `[1.09091,1.24713,1.36620]` [J `evidence/head-report.json:332-355`; J `history/robin-transfer-9-before-donor-head/native/build_head.py:385-399`].

   `repair_color_line` delegates to `atlas_surface.color_line_repair`: project a color onto an explicitly supplied shadow-to-skin line, smoothstep a chromatic residual and spatial edges, then lift within the specified normalized top-down box [behaviour; J `native/nape_atlas.py:10-37`]. `repair_root_paint` uses the **original** image for orange ordering `R>G>B`, a saturation smoothstep per explicit box, and intersects the resulting weights with a spatial eligibility field. The recipe supplies `boxes`, `saturation_ranges`, and a boolean `nearby_mask` of local clean skin. Initialize selected pixels from the local median, perform four-neighbour harmonic fill and blend by the eligibility weights. [single-subject] 400 iterations were used [J `native/hairline_atlas.py:33-112`]. Unlike legacy `np.roll`, which wraps opposite array edges, the implementation uses bounded edge replication. It never selects naturally dark pixels merely for being dark. A missing original selection or local skin sample is an error.

5. **Details.** `recolor_details` accepts `boxes` named `iris`, `brow`, `crease`, optional full-image boolean eligibility masks in `predicates`, and a `palette` with `background`, `iris_dark`, `iris_bright`, `brow_dark`, `crease_multiply`. Pixels within .12 RGB distance of the background and highlights (encoded luminance >.85 and saturation <.2) are protected. Iris interpolation is `clip((L-.03)/.45,0,1)^.9`; brow adds `.1L*[1,.9,.9]` to its supplied dark color; crease multiplies by the supplied factor. Painted lashes and highlights must be preserved as separate details; a box alone does not identify their ownership. [single-subject; J `history/robin-transfer-9-before-donor-head/native/build_head.py:289-315`].

   `recolor_iris` is a separate donor pigment operation. Supply `thresholds` keys `saturation`, `maximum`, `blue_ratio`, `green_ratio`, a hue in [0,60], and optionally a UV `coverage` mask. [single-subject] Criteria `sat>.2`, `max>.08`, `B>1.1R`, `G>1.02R` select pigment and map it to `[max,min+(max-min)*hue/60,min]` with hue 42° [J `native/transplant_head.py:491-508`; J `native/halloween-parameters.json:941-943`]. Non-pigment pixels are byte-identical; counts distinguish changed, pigment and protected. Full-map results and UV-covered counts are different domains: [single-subject] 8,491 changed and 7,893 protected full-map pixels versus 5,997 UV-sampled pigment texels [J `evidence/head-10-halloween-native.json:475-500`; J `evidence/head-10-authoring-smoke.json:3-18`].

6. **Composite and bridge for a transplanted head.** `build_composite` delegates to `atlas_surface` and takes bottom-up opaque uint8 body `W × W/2`, donor face and neck square images, and two ring sample arrays or owner-UV dictionaries. The atlas is `W × 9W/8`: body bytes copied exactly; donor squares occupy the next band; bridge occupies the last `W/8` rows. Body, face and neck UVs map to `(u,4v/9)`, `(u/2,4/9+4v/9)`, `(u/2+.5,4/9+4v/9)`; return values expose remapping callables. For each bridge column, repeat-bilinear sample the ring, decode sRGB, smoothstep blend in linear light and re-encode. [behaviour; J `native/transplant_head.py:382-403,447-488,759-773`]. A 2× donor resample is supported; an incompatible body or donor is rejected. This does not repair alignment or topology.

7. **Padding, save, pack, verify.** Island dilation and bridge endpoint padding are separate. Bridge padding is `4W/2048` pixels [behaviour; J `native/transplant_head.py:475-488`]; do not apply unrestricted dilation to shared UVs. `save_pack_verify(image,path,packed_bytes=None)` writes an opaque RGB/RGBA PNG with an sRGB chunk, reads its bytes back, compares supplied packed bytes exactly when provided, and reloads decoded pixels. Its returned `packed_bytes` are the saved bytes; it does not implicitly mutate Blender. `pack_blender_image(image, receipt['packed_bytes'])` explicitly packs them, and raises a clear error without bpy. Caller must wire the intended material node and independently inspect the actual packed/exported bytes. Packing an image without explicit saved bytes can retain stale pixels [behaviour; J `native/transplant_head.py:411-430,790-803`]. A supplied stale buffer fails instead of being reported as a pass.

8. **Skin material and export.** Pass explicit values to `skin_material_spec(params)`: `metallic`, `roughness`, `ior`, `subsurface_weight`, `subsurface_radius`, `subsurface_scale`, `detail_roughness`, and booleans `base_color_map`, `normal_map`, `roughness_map`. [single-subject] Native values were metallic 0, roughness .5, IOR 1.4, subsurface weight .08, radius `(1,.45,.2)`, scale .002 and separate detail roughness .35 [J `history/robin-transfer-9-before-donor-head/native/build_head.py:430-461`; N `native/prepare_character.py:121-141`]. `validate_skin_material(spec, exported)` checks claimed maps, base color sRGB, data maps linear, metallic and roughness against supplied export observations. Missing maps fail. Native scattering is reported **not exported**, not claimed as browser SSS; no scan-derived micro-detail is established, so `micro_detail` is `unmeasured` rather than a fictional normal map. This validator consumes observations, not a GLB parser.

## Failure log and limits

- [single-subject] A blocky leg strip had 1,704 pixels deviating over .08 from its median; flat measured fill addressed that paint, not geometry [J `evidence/head-report.json:315-330`].
- [single-subject] Bounded nape repair changed 26,687 pixels and zero outside its nape mask [J `evidence/nape-08-blue-native.json:9-41`].
- [single-subject] A donor neck initially sat 2.6–2.7 cm rearward; geometric alignment was required rather than hiding a step with atlas blending [J `README.md:110-113`].
- [behaviour] Packing alone can retain stale bytes; explicitly pack saved bytes and compare [J `native/transplant_head.py:411-430`].

### What is not established

- No scan-derived pores or micro-detail were authored; `unmeasured` is not a pass.
- No browser subsurface scattering is established by native settings; the examined exported skin had no normal or roughness map [single-subject; N `native/prepare_character.py:121-141` and `reference/nami-construction-study.md:96-102`].
- Painted features and shadows are not measured reflectance, and no de-lighting was performed [behaviour; J `history/robin-transfer-9-before-donor-head/native/build_head.py:251-256`].
- UV coverage, mask protection and pixel checks do not prove appearance, source rights, or geometric correctness.
