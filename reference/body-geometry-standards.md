# Body geometry, topology and UV (S9)

These measurements describe only caller-selected neutral meshes. They do not authorize chest, hip, buttock or sexualized detail. Geometry references, tolerances, limits and baselines belong to the caller. No historical subject range is shipped; missing measurements never pass.

## Running and declarations

Run `bpy_measure_geometry.py --blend candidate.blend --reference reference.blend --landmarks landmarks.json --regions regions.json --mirror mirror.json --join-boundary GROUP --atlas-size 2048x1024 --budget budget.json --out evidence.json`. Optional inputs are required only for the measurements they enable. Blender opens files without scripts or saving. All coordinates are rest mesh coordinates transformed by each object's world matrix; Z is up and the scope's Z bounds define H. Select only intended body objects: hair or accessories can change H. Units assume Blender world units are metres. Files should be evaluated in the same frame and pose.

JSON inputs:

* `regions`: `{"objects":["Body"],"regions":{"face":{"Body":[0,1]},"body":{"Body":[2,3]}},"approved_island_pairs":[["Body:0","Body:5"]]}`. Regions explicitly list **polygon indices**, and island IDs are `object:root-polygon-index`; inspect the mesh's UV-connected polygons before authoring approvals. Only explicitly approved pairs may overlap; approval also exempts that pair from gutter measurement. Use a shared atlas only for meshes/materials that actually share it. Multiple material atlases must be measured separately by object scope. Empty/unknown regions are unmeasured.
* `landmarks`: `{"points":{"shoulder":{"object":"Body","group":"Shoulder"},"wrist":{"object":"Rig","bone":"Hand"}},"pairs":[["shoulder","wrist"]],"pose":{"shoulder":"shoulder","wrist":"wrist"},"head_pair":["head_top","chin"],"shoulder_pair":["left_shoulder","right_shoulder"]}`. A vertex group denotes its nonzero-weight vertex centroid; a bone denotes its rest head. Names and object names must exist in both blend files. Length/H ratios are compared pair by pair; a missing or occluded point makes the whole comparison unmeasured. A-pose angle is shoulder-to-wrist versus vertical, not the historical cluster-axis angle.
* `mirror`: `{"plane":{"point":[0,0,0],"normal":[1,0,0]},"tolerance_m":0.001,"exclude_group":"intentional-asymmetry"}`. The exclusion is a vertex group explicitly marking intentional asymmetry. Nearest opposite-side vertices are tested in both directions; points exactly on the plane are excluded. Coverage counts the eligible points within tolerance; p95 and maximum are for matches and must be judged together with coverage. UV sharing is an additional historical diagnostic, not authorization of overlap.
* `budget`: `{"parts":{"Body":"body"},"limits":{"geo_triangles_body":{"value":10000,"source":"project budget"}}}` maps mesh names to semantic part suffixes. Counts are rest native mesh vertices and triangulated polygons, not evaluated modifiers or exported split vertices. The example number is illustrative, not a standard.
* Any declaration file may supply `references`, `baselines`, and `limits`, merged into the evidence. For `reference-within`, use `{"references":{"geo_landmark_ratio_max_delta":{"value":0,"tolerance":0.02,"source":"approved same-pose reference"}}}`. A baseline contains `value`, `factor`, `epsilon`, `source`; a minimum or maximum contains `value`, `source`. Numbers above are examples only. The independent gate checks declarations and provenance.

Whole-mesh topology is position-welded in a temporary array with a 1 micrometre tolerance; incidence 1 is boundary, more than 2 is nonmanifold, and zero area is checked after welding. `--join-boundary` names vertex groups whose selected edges are the promised interface. At least one selected vertex is needed; the caller must select the complete interface. This is not a curve gap, intersection, disconnected-component, or zipper-triangle test and does not prove two adjacent separate objects are welded elsewhere. Whole-body boundary edges compare to a declared baseline rather than assuming every shell is closed.

UV triangles are grouped into islands by mesh-edge and identical endpoint UV connectivity. Pixel-centre rasterization uses the supplied width and height; nonapproved overlapping triangle interiors count once per texel. Gutter is the shortest distance between occupied texel centres of different unapproved islands minus one pixel, clamped to zero. These are finite-resolution samples, not exact continuous overlap or mip/filter simulation; subpixel geometry and triangles touching only at boundaries may be missed. Density is `sqrt(sum(triangle UV area * width * height) / sum(world triangle area))` per declared region, counting mirrored triangle area repeatedly, following `tools/character_prior/anatomy.py:1037-1068`. It is not unique atlas occupancy, an island median, or anisotropy. A single island or only approved overlapping pairs has no measurable inter-island gutter.

If any UV triangle contains no sampled texel centre, overlap and gutter are omitted as incomplete, while area-based density remains available. Loose edges also count as nonmanifold. A join must contain at least one selected edge, not merely a group or vertex, to yield a join measurement.

## Evidence and limitations

Only caller-declared reference values are valid. Hair/accessories can change measured height and heuristic silhouette bands; use the same selected scope and pose on each side of a comparison.

A locally closed join does not prove a globally closed body. Inspect actual adjacency, silhouette and correspondence; color repair cannot conceal an uncorrected geometric offset.

Unmeasured by design: camera-calibrated landmarks and occlusion, independently established hand/foot lengths, positional correspondence between different topologies, posed self-intersection, continuous motion, true filter bleed, exact continuous UV overlap, cross-material separation, and final export counts. A numeric gate cannot replace visual inspection.
